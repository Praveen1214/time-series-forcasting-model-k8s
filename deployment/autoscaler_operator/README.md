# Autoscaler Operator

Custom Kubernetes operator for predictive autoscaling using the Informer model.

## Overview

This operator will:
1. Monitor Kubernetes pods and collect telemetry
2. Send telemetry to the prediction service
3. Receive pod count predictions
4. Adjust replica counts proactively
